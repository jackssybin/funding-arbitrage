# 多币种资金费率套利机器人 v2.0

一个功能完整的币安合约资金费率套利机器人，支持多币种轮动、杠杆优化、自动移仓和网格增强四大核心功能。

## ✨ 四大核心功能

### 1️⃣ 多币种轮动 🔄
- 实时监控 BTC、ETH、SOL、XRP、DOGE 等多个主流币种
- 自动选择资金费率最高的币种开仓
- 支持同时持仓多个币种（可配置）
- 费率排行一目了然

### 2️⃣ 杠杆优化 ⚖️
- 支持 2-3 倍杠杆提高资金利用率
- 自动为每个币种设置杠杆
- 按 USDT 价值计算开仓数量（不是固定币数）
- 推荐 3 倍杠杆，风险可控

### 3️⃣ 自动移仓 📦
- 当发现更高费率的币种时，自动判断是否值得移仓
- 配置移仓阈值（如费率高 0.03% 才移仓，避免频繁操作）
- 平仓费率低的币种，开仓费率更高的币种
- 实现资金收益最大化

### 4️⃣ 网格增强 📊
- 持仓期间在上下挂网格小单
- 通过价格震荡赚取额外收益
- 可配置网格层数和间距
- 价格偏离过多时自动重新平衡网格
- 平仓时自动取消所有网格单

## 🛡️ 风控与安全措施

### 核心风控
- ✅ 单日最大亏损限制
- ✅ 账户最低余额要求
- ✅ 最大回撤保护（触发后全平）
- ✅ 止损百分比配置
- ✅ 模拟模式（默认开启，不下真实单）

### 两道硬核安全防线 🔥

#### 防线1: 精度裁剪与对齐 (StepSize / TickSize)
- 自动从 exchangeInfo 获取每个币种的精度规则
- 下单前自动对齐 stepSize（数量精度）和 tickSize（价格精度）
- 彻底避免 "Filter failure" API 拒单错误

#### 防线2: 原子性回滚防单边敞口 ⚠️
- 现货买入和合约做空通过事务管理器保证原子性
- 失败自动重试 3 次，极端情况自动反向回滚
- 彻底避免单边裸敞口的致命风险

### 三大实盘盈利优化 💰

#### 优化1: 并发发单消除时间差滑点
- 使用 `CompletableFuture` 让现货和合约请求**同时发出**
- 两笔订单几乎在同一毫秒抵达币安服务器
- 消除串行 0.5 秒时间差导致的 0.2% 不对等滑点
- 节省的滑点 = 2 天的资金费纯利润！

#### 优化2: 智能下单防盘口击穿
- 下单前**实时查询 OrderBook 盘口深度**（前 5 档）
- 如果订单量超过盘口深度的 50%，自动拆成多笔小单
- 每笔小单间隔 200ms，避免冲击市场
- 特别适合 DOGE 等小币种的大额开仓

#### 优化3: 保证金守护线程防爆仓
- 后台守护线程每 30 秒检查一次保证金率
- 低于 10% 发出预警，低于 5% 紧急补仓
- 自动调用 Universal Transfer API 从现货划转 500 USDT 到合约
- 极端插针行情下的最后一道防线，3 倍杠杆也不怕爆

## 🚀 快速开始

### 1. 环境要求
- Java 17+
- Maven 3.6+
- 币安 API 密钥（只开通现货和合约交易权限）

### 2. 配置
```bash
cp .env.example .env
# 编辑 .env，填入你的 API 密钥
```

### 3. 编译运行
```bash
mvn clean package
java -jar target/funding-arbitrage-1.0-SNAPSHOT.jar
```

## ⚙️ 配置说明

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `TRADING_SYMBOLS` | BTCUSDT,ETHUSDT,SOLUSDT,XRPUSDT,DOGEUSDT | 监控币种列表 |
| `MAX_POSITIONS` | 3 | 同时持仓的最大币种数 |
| `LEVERAGE` | 3 | 杠杆倍数（推荐 2-3） |
| `POSITION_VALUE_USDT` | 1000 | 单币种仓位价值 USDT |
| `FUNDING_RATE_THRESHOLD` | 0.0005 | 开仓阈值 0.05% |
| `FUNDING_RATE_CLOSE_THRESHOLD` | 0.0002 | 平仓阈值 0.02% |
| `SWITCH_THRESHOLD` | 0.0003 | 移仓阈值 0.03% |
| `GRID_ENABLED` | true | 启用网格交易 |
| `GRID_LEVELS` | 5 | 网格层数 |
| `GRID_SPACING` | 0.003 | 网格间距 0.3% |
| `SIMULATION_MODE` | true | 模拟模式（重要！） |

## ⚠️ 重要提示

1. **先跑模拟！** 默认开启 `SIMULATION_MODE=true`，确认策略没问题再改为 `false`
2. **API 安全！** API 密钥只开通现货和合约交易权限，不要开通提币权限
3. **杠杆谨慎！** 建议从 2-3 倍开始，不要用高杠杆
4. **从小资金开始！** 实盘先用小资金测试
5. **资金费率风险！** 资金费率可能变负，做多会亏损，程序会自动处理

## 📈 收益预期

假设日均资金费率 0.01%，一年 365 天，每天 3 次结算：

- 基础年化：0.01% × 3 × 365 ≈ 11%
- 3 倍杠杆：≈ 33%
- 网格额外收益：+5~15%
- **扣除手续费后：30~40% 年化（理论值，不保证）**

实际收益受市场费率波动、手续费、滑点等因素影响。
