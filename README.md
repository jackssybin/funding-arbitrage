## 🚀 快速开始

### 1. 环境要求
```
Java 17+
Maven 3.6+
```

### 2. 编译打包
```bash
mvn clean package -DskipTests
```

### 3. 配置环境变量
```bash
# 复制模板
cp .env.example .env

# 编辑配置
vim .env
```

### 4. 启动
```bash
# Linux/Mac
java -jar target/funding-arbitrage-1.0.0.jar

# Windows
start.bat
```

### 5. 访问仪表盘
打开浏览器：`http://localhost:8080`

## 🎯 核心策略参数

| 参数 | 默认值 | 说明 |
|-----|-------|-----|
| **正费率开仓阈值** | 0.15% | 做空赚资金费 |
| **负费率开仓阈值** | 0.20% | 做多赚资金费（风险更高） |
| **平仓阈值** | 0.03% | 费率太低就平 |
| **移仓阈值** | 0.10% + 手续费 | 满足才移仓 |
| **单币止损** | 2% | 亏2%就跑 |
| **单币止盈** | 3% | 赚3%就走 |
| **最大持仓数** | 3-5个 | 分散风险 |
| **杠杆倍数** | 2-3倍 | 保守为主 |

## ⚠️ 风险提示

1. **本策略不保证盈利**，历史回测不代表未来收益
2. **一定要先跑模拟盘**，验证1个月再上实盘
3. **从小资金开始**，建议初始资金不超过5000USDT
4. **永远不要all in**，资金分散到多个交易所
5. **每天检查**，不要放着不管
